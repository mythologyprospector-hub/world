# Mythology Prospector World

> The durable landing point for the mythologyprospector-hub project world.

This repository is the **world-level orientation layer**.

It does not own the internal architecture of the projects it maps. Each project remains sovereign and keeps its own canon, architecture, tests, and decisions.

## Start here

For a fresh session, **the World URL by itself is the launch command**. The assistant must open [HANDOFF.md](HANDOFF.md), follow the arrival protocol, and begin the actual account-wide orientation and survey. Do not reply with only a greeting or ask the owner what to explore; the assistant is responsible for discovering what needs attention and recommending the next direction. The owner should not need to remember project names, reconstruct yesterday's conversation, or choose which repository to inspect first.

The governing references are:

1. [GENIE_PROTOCOL.md](GENIE_PROTOCOL.md) — learn how to ask, give the wish a durable home, then drive the work.
2. [AGENT.md](AGENT.md) — world-level agent boundaries.
3. [WORLD.md](WORLD.md) — mission and project sovereignty.
4. [WORKFLOW.md](WORKFLOW.md) — working method, Miracle Tokens, and long-running work.
5. [REPOSITORIES.md](REPOSITORIES.md) — public project map.
6. [MACHINE.md](MACHINE.md) — local development layout.
7. [JIMMYDEV.md](JIMMYDEV.md) — the human purpose and standards behind the work.

## Governing idea

**The whole GitHub world is the unit of orientation. Individual repositories are the units of ownership and implementation.**

The world map tells an agent where to look. Project canon tells it what is true inside that project.

## Authority

This repository is authoritative for **world-level orientation and workflow only**.

It must never silently override a project's own canon.
